Bit.krshr as Plugin

plugin version of the Bit.krshr effect pedal

ready to use as Standalone and as .vst on DAWs

as a regular DAW and plugin user, i always dreamt about writing my own plugin.

for this goal i wanted to convert my Bit.krshr Effect Pedal in a basic plugin, so that i can deepen my basic knowledge in C++ and get to know JUCE Framework

builts for Windows made with jumake by BaraMGB

Plugin in Action on a DAW

Note that the video can get loud!
