MathGame

a simple quiz-game with aritmetic questions to train my skills after Java classes

How does the game work?

Math Game is a fast-paced arithmetic quiz built with Java Swing.

You get a countdown and random questions, type your answer and check it. Every correct answer adds 3 seconds, every wrong answer lowers your score. When the time runs out, you win with a score of 6 or more.

The game has a retro pixel look, custom buttons, and sound effects and background music that I made myself.

What have i learnt?

  • Building a desktop app with Swing: JFrame, JPanel, layouts and CardLayout for switching screens
  • Event handling with listeners, lambdas and javax.swing.Timer for the countdown
  • Custom graphics: my own GameButton and a polygon-shaped question box using paintComponent
  • Splitting a project into small classes, each with one job
  • Playing sounds with Clip and loading a custom font with Font.createFont
  • How absolute file paths break a project when the folder moves, and how to export a runnable .jar
  • Creating my own music and sound effects and using them in a Java game

Known Issues

  • Background music plays only once. It stops after the track ends instead of looping. Looping needs just one extra line (clip.loop(Clip.LOOP_CONTINUOUSLY)).
  • Questions can repeat. The next question is picked randomly from the whole pool, so the same one can appear twice in a row or again after pressing "Next Question". I wrote this part before I learned how to remove items from a list and shuffle it properly.
  • "Try again!" keeps the wrong color. After a correct answer, the next "Try again!" text still shows in green.
  • The source code uses absolute file paths. The sound and font files are loaded from folders on my own computer, so the source code only finds them there. Loading them with getResource would fix this.

Download

You can download the runnable .jar file of the game here: MathGame.jar
Note that you need to have Java installed on your computer to run it. You can get the latest version of Java from the official website: https://www.java.com/en/download/
