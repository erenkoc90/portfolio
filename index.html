Hi!
I'm Eren.
I am a junior software developer in training, currently completing a career transition program (Umschulung zum Fachinformatiker für Anwendungsentwicklung) in Berlin. I'm especially interested in the place where code meets sound and play: audio software, programming music hardware, and games.
This website is my portfolio. It shows what I've built so far and how I work.
What I've built:
• Hardware & C++: Bit.krshr, a DIY guitar effect pedal running on an Arduino Nano-compatible board, programmed in C++.
• Audio plugin with JUCE (C++): I ported Bit.krshr to a plugin that runs standalone and as a VST in a DAW (tested in Ableton Live). It was my first project with the JUCE framework.
• Web development: kotka.la, a portfolio website for an independent artist.
• Browser games in vanilla JavaScript: a memory game played against the clock, and a small action game with collision mechanics and basic enemy AI. Both use the artist's characters as pixel-art assets
• Currently exploring: Deeper audio programming with JUCE and game development in Unity (C#).
Have a look at my PROJECTS to see the code in action.
